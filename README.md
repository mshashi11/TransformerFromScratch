# TransformerFromScratch

The goal of this repository is to build a Transformer Model in Python from scratch, that can be run on a single machine with reasonably advanced architecture.

Configuration of the machine on which this code is being currently developed:

1. CPU: AMD Ryzen 9 7900X 12-Core Processor, 24 vCPU
2. GPU: RTX 4080 Super
3. Memory: 64 GB RAM
